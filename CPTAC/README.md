# CPTAC Pan-Cancer Proteogenomics (T2 dataset `cptac`)

The CPTAC Pan-Cancer harmonized data freeze v1 (BCM pipeline, GENCODE v34; Li et al., Cancer Cell
2023;41:1397-1406) in the T2 schema: ten cohorts (BRCA, CCRCC, COAD, GBM, HNSCC, LSCC, LUAD, OV, PDAC,
UCEC), tumors and normal adjacent tissue, six data types. Data generated by the National Cancer
Institute Clinical Proteomic Tumor Analysis Consortium (CPTAC).

Binding specification: `SPEC.md`. Measured facts about the raw files: `Data/profile.md`.

## Files

| file | what |
|---|---|
| `00-download.R` | fetches the PDC pan-cancer zips and the LinkedOmicsKB mirror into `Data/` (idempotent) |
| `01-profile.R` | profiles the raw files into `Data/profile.md` |
| `build_cptac.R` | the builder: `Data/` -> `datasets/cptac.db` |
| `test_cptac.R` | unit tests of the builder's helpers, facts and spot values of the built db, then the generic suite |
| `Data/` | downloaded files (untrusted, gitignored; read with `fread` only) |

## Build and test (inside the R container, repo root `/home/rstudio/R/T2`)

    Rscript CPTAC/build_cptac.R > CPTAC/build.log 2>&1      # full build, about 8 minutes, 7 GB
    Rscript CPTAC/test_cptac.R                              # ends with the generic sql_tests suite
    Rscript test_multidataset.R

The build writes `<OUT>.building` and renames it on success. Env knobs: `CPTAC_OUT`, `CPTAC_COHORTS`
(comma list), `CPTAC_TYPES` (default `rna,prot,phospho,cnv,mut,fmut`), `CPTAC_SUBSET_GENES` (rows of
rna/prot/phospho/cnv, for smoke builds), `CPTAC_CHUNK` (probes per insert). Smoke build:

    CPTAC_OUT=/home/rstudio/R/T2-devdata/scratch/cptac-smoke.db CPTAC_SUBSET_GENES=800 \
    CPTAC_COHORTS=CCRCC,OV Rscript CPTAC/build_cptac.R

## Key data decisions

- **Samples**: the case universe of a cohort is the `idx` of its PDC `*_meta.txt`. Tumor sample = case
  id; normal adjacent tissue = `<case>_N`. Columns whose case is not in the meta are dropped (logged).
  `sample_type` is `Primary Tumor` or `Solid Tissue Normal`; cohort column is `cancer_type`.
- **Symbols**: `gene_name` of the mapping table, looked up by the versioned Ensembl id.
- **Probes**: `CD8A` (rna, bare), `CD8A.prot`, `MAPK1_Y187.phospho`, `CD8A.cnv`, `TP53.mut`, `TP53.fmut`.
- **rna**: the LinkedOmicsKB TPM files, log2(TPM+1); only the genes present in all ten files; negatives
  clamped to 0; genes sharing a symbol summed in linear space; zeros not stored (sparse, default 0).
- **prot, phospho, cnv**: values as shipped, `-Inf`/NaN -> NA, NA = no row (sparse = 0). Two Ensembl ids
  on one symbol: the one with more non-NA values over all cohorts is kept. Phospho: per (gene, site)
  the ENSP with the most non-NA values; duplicate (gene, ENSP, site) rows within a file: the one with
  more non-NA. cnv: genes with a protein_coding transcript only.
- **mut**: binary file, only the 1s stored (sparse, default 0), tested = all columns of the file.
  **fmut**: the MAF, `Hugo_Symbol_aaChange_Variant_Classification` (`*` -> `s`, empty -> `NA`), all
  variant classes, in `tcgacati`.
- **clinpheno**: PDC meta union (names normalised, survival renamed OS/OS.time/PFI/PFI.time); CON
  columns numeric, BIN/ORD as text, events numeric 0/1; normal samples keep only the case-level columns.
- Each cohort has its own protein/phospho reference: compare protein abundance across cohorts with care.
