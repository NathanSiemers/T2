(Written by hand from the measurements above; the numbers refer to sections 0 to 10.)

1. **Tumor/Normal id reuse is the rule, with exceptions.** In CCRCC, HNSCC, LSCC, LUAD, PDAC the Normal files use the SAME id string as the Tumor files (e.g. `C3L-01287` in both): all Normal ids are a subset of the Tumor ids. Normals carry no suffix or prefix, so the builder must add its own tumor/normal marker (the file name, Tumor/Normal, is the only source of that information in the matrices). Exceptions: COAD (100 normal vs 97 tumor ids, 96 shared; meta has 110 rows), OV (19 normal ids, only 10 shared with tumor), UCEC (18 normals named `NX1`..`NX18`, no overlap with any tumor id, so they cannot be tied to a case).
2. **The meta `Tumor`/`Normal` columns are Yes flags, not a per-sample type.** `Tumor` is `Yes` for every row in 8 of 10 cohorts (including cases that have only a normal sample), `Normal` is `Yes` when the case has a normal file. UCEC meta contains the 18 `NX*` rows plus 95 tumor rows. So one meta row = one case id (or an NX id), not one sample.
3. **Odd ids**: BRCA has a numeric id `604` in every data type (and TPM has `100002921`, `1488`...); LUAD mixes `C3L-`/`C3N-` ids with four `11LU0xx` ids; the TPM mirror has ids not in the PDC UQ files (CCRCC 7, PDAC 66 stripped ids, OV 19, BRCA 12). Sample ids are never shared between cohorts (0 of 2308 distinct ids).
4. **TPM mirror found for all 10 cohorts, but it is a different sample set and id scheme**: the 7 `removed_circRNA` files use `_T`/`_A` suffixes (tumor/adjacent normal; HNSCC 109 T + 61 A etc.), have 59361 genes instead of 60669, a header without corner cell (one field fewer than the data lines), values from -0.01 (small negatives in log2(x+1)). BRCA, COAD, OV TPM files use bare ids and 60669 genes. Normal/tumor counts in TPM do not equal those of the UQ files (e.g. CCRCC 110 T + 75 A vs 103 T + 72 N). Mixing the two RNA sources needs an id-normalization rule and an explicit decision which source is canonical.
5. **BRCA, COAD, OV RNA UQ median is 0** and 54-56 percent of cells are exactly 0, against about 37 percent and median about 2.1 in the C3L/C3N cohorts: these cohorts were quantified differently, so cross-cohort comparison of RNA UQ is not like for like.
6. **Phospho matrices contain `-Inf`** (BRCA 551, GBM 2255, OV 1557 cells, ...; see section 1) besides NA. `-Inf` must be mapped to NA (or dropped) before loading into a REAL column; 0 is not used. Phospho NA fraction is 0.43 to 0.67, the proteome NA fraction 0.13 to 0.25.
7. **Line endings**: proteome Tumor/Normal, meta, phenotype, case lists, and for LUAD also CNV, mutation binary and MAF have CRLF; phospho, RNA, TPM and the other cohorts use LF. fread copes with both, but a hand parser must strip `\r` (last column name would otherwise end in `\r`).
8. **Gene ids**: all matrix ids are GENCODE v34 style Ensembl ids WITH version (`ENSG00000000003.15`), 45 of 60669 RNA ids end in `_PAR_Y` instead of a numeric version (and the mapping table has them identically). Every id in proteome, RNA, TPM, CNV, mutation binary and phospho is found verbatim in the mapping table (0 version mismatches), so the same table serves all data types. Proteome sets differ per cohort (9151 to 12760 genes, 7783 common to all 10, 15100 in the union); RNA and CNV row sets are identical across cohorts (60669 / 60603), the mutation binary files list only mutated genes (3362 to 15487 genes) and mutation/TPM sets differ per cohort.
9. **Symbols**: the mapping table has a non-empty `gene_name` and `gene_name_BCM_refined` for every one of its 60669 genes. `gene_name` has collisions (proteome: only `HSPA14`, 2 ids; table-wide 78 symbols are shared by more than one gene id), `gene_name_BCM_refined` is collision-free because BCM appended `_ENSG...` or `_PAR_Y` to 78 symbols (e.g. `ABCF2_ENSG00000285292`). The refined symbol is therefore not always a clean HGNC symbol; the builder must decide whether to strip the suffix for display (it would recreate the collisions) or keep it.
10. **Phospho row id** is `ENSG|ENSP|site|peptide|n` with a pipe delimiter: gene and ENSP are versioned, the site token is always a single `[STY]digits` (no multi-site tokens, no odd characters, 127040 distinct rows over all cohorts), the 5th field is 1 or 2 (meaning not documented in the files; probably the number of phosphosites in the peptide, unverified). (gene, site) pairs with more than one ENSP occur (e.g. 27 in BRCA, 201 in HNSCC; 344 distinct overall), so the (gene, site) key is NOT unique; (gene, ENSP, site) is unique in every file (no repeated peptides per triple). Phospho genes: 11438, 96 percent also in the proteome row sets.
11. **MAF**: 93 columns, identical in all cohorts; `gene_name` and `Gene.refGene` hold Ensembl ids, the real HGNC symbol is in the later column `Hugo_Symbol`; protein change is in `aaChange` (no `HGVSp_Short` column), sample id is `Tumor_Sample_Barcode` and equals the proteome-style id (BRCA `604` included). Variant classes include non-coding ones (Intron, IGR, RNA, Silent, Flank, UTR). The MAF has many more rows than the binary file has set cells (binary = per gene and sample 0/1, genes limited to those with a mutation).
12. **Meta**: 293 distinct columns over 10 cohorts, 187 in all cohorts; types CON/BIN/ORD/data_type only (no CAT); no type conflicts between cohorts. Cohort-specific columns are almost all `{GENE}_mutation` flags (45 distinct genes, different per cohort; OV has `mutation_table`). One meta column, `POLE`, equals an HGNC symbol (a POLE status flag, not the gene's expression): the dataset's column namespace must not mix meta fields with gene symbols without a prefix. Several column names contain `/`, `+`, `(`, `-` (`PTM_SEA_KINASE-PSP_Akt1/AKT1`, `CIBERSORT_T_cell_CD4+_naive`), so they need quoting or normalization as field names. Survival: OS/PFS days and events are present for every cohort but fill 67 to 100 percent (BRCA OS_days 79 percent, OV PFS_days 67 percent).
13. **Mirror survival/phenotype/meta add nothing new**: the mirror survival rows equal the PDC meta OS/PFS values for the same ids (fraction 1.0 in all cohorts); phenotype is the CIBERSORT/xCell/ESTIMATE/... block of the meta (UCEC has one column not in the PDC meta; check in section 7); mirror meta is a reduced subset (12 to 35 columns). The PDC meta files are byte-identical to the copies under `README/` in the proteome zip.
14. **Naming**: the RNA, CNV, Mutation and Clinical zips call the cohorts `ccRCC` and `HGSC`; proteome, phospho and mirror use `CCRCC` and `OV`. The cohort-size xlsx is not listed separately in the PDC listing; it is inside the proteome zip `README/` (its counts match the meta rows: BRCA 122 tumor/0 normal, ... UCEC 95/18) and does not equal the number of normal files for COAD (100) and OV (20 vs 19).
15. **PDC API**: `file_size` is null for every file; the manifest therefore records sizes measured after download (`downloaded_sizes.tsv`). The signed URL endpoint sometimes answers 502/503 for a moment, the download script retries.
